MCP 接入

本机 · 无需认证
传输
Streamable HTTP，配置类型为 http
填写规则
填写完整 URL（协议、地址、端口、/mcp）；只填 IP 不行。不要填启动命令、SSE 路径或令牌。

客户端配置

支持 URL 表单的客户端，添加名为 recallport 的 Streamable HTTP 服务并粘贴地址。使用配置文件的客户端，选择对应示例并合并到现有配置。

Codex ~/.codex/config.toml
[mcp_servers.recallport]
url = "{{.Base}}/mcp"
Claude Code .mcp.json
{
  "mcpServers": {
    "recallport": {
      "type": "http",
      "url": "{{.Base}}/mcp"
    }
  }
}

客户端须能访问本机端点。云端、容器、WSL 或另一台设备的 127.0.0.1 不一定指向运行 RecallPort 的 Windows。

工具参考 3 个

remember 追加一段经历
必填
text：正文。
可选
context：情境；occurred：发生日期；source：自报来源；origin：同一次经历的共同标识；request_id：同一次写入重试用；references：[{id, reason?}]。
返回
已写入的记录、稳定 ID、来源和写入时间。不会改写旧记忆。
{"text":"登录后在后台启动","occurred":"2024-09","source":"Codex"}
recall 按场景、关键词或日期回忆
可选
query：检索文字；strategy：hybrid（默认）、lexical 或 semantic；from / through：发生时间范围；limit：1–30，默认 8。不传 query 则浏览时间线。
返回
memories 含摘要、ID、日期和来源；mode 是实际使用的检索模式；more 表示结果已截断；degraded 表示搜索已降级。
{"query":"开机自启","strategy":"semantic","from":"2024","limit":5}
read 展开一条记忆
必填
id：由 recall 或 remember 返回的记录 ID。
返回
正文、情境、时间、来源、引用和反向引用。

日期支持 YYYY、YYYY-MM、YYYY-MM-DD；不确定时可留空。不要让旧记忆代替当前事实或授权。
